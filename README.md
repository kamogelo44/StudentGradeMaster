# Student Grade Calculator

A Java program for calculating and managing student grades.

## What This Program Does

- Add student names and marks for 5 subjects
- Automatically calculates total marks and average percentage
- Assigns grades (A, B, C, D, F) based on performance
- Shows class summary with statistics
- Stores up to 10 students at a time

## How to Run

1. Make sure you have Java installed
2. Open the project in NetBeans or any Java IDE
3. Run the StudentGradeCalculator.java file
4. Follow the instructions on screen

## Sample Usage
Enter student first name: John
Enter student last name: Smith
Enter marks for 5 subjects:
Subject 1 mark: 85
Subject 2 mark: 92
Subject 3 mark: 78
Subject 4 mark: 88
Subject 5 mark: 95

Student Report:
Name: John Smith
Total Marks: 438/500
Average: 87.6%
Grade: B

## Grade System

- A: 90-100%
- B: 80-89%
- C: 70-79%
- D: 60-69%
- F: Below 60%
